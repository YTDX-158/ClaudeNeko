定向覆盖包括：

- ask/smart 会话级注入明确的询问工具规则，bypass 保持完全访问模式。
- Windows 路径、引号、CRLF、完整 user 行、8 MiB 边界、旧文件、歧义候选及非法 UUID 均按预期处理。
- 映射权限请求生成卡片并标记 pending；未映射请求返回 404，日志仅保留安全短标识。
- CR/LF、ANSI 和非 RFC UUID 不能注入诊断日志。
- 权限模式切换串行执行，切换期间跨会话 PTY 启动被阻止；超时不落新配置。
- 待审批记录使用 15 分钟 TTL；决定由 Hook 取走后即消费，会话停止会关闭该 sid 的全部卡片和记录。
- “以后都行”只记完整 Bash 命令或完整文件路径；写盘失败返回非 2xx，卡片保留以便重试。
- 广播与重连恢复使用同一脱敏 DTO，不返回完整 `tool_input`；摘要和范围文本限制长度，命令中的换行显示为可见的 `\n`，不会隐藏执行语义。
- 刷新、切换会话和 WebSocket 重连均恢复未决卡片；迟到快照不会复活已关闭卡片，停止成功会使在途旧快照失效，网络失败后按钮可再次操作。
- 用户已有 `PermissionRequest` Hook 被保留；只去重路径与当前 ClaudeNeko 脚本完全一致的 Hook，来源无法验证的旧路径也保留，安装失败只记录 warning，服务继续启动。
- 已配对远端可逐次响应权限卡片，但无法读取或修改权限模式/规则，也不能切换到 bypass。
- Hook 在记录已取消时收到 404 会快速退出；自定义 `PORT` 会由 Hook 正确继承。
- 缺少完整命令/路径时拒绝保存长期规则；规则身份保留原始字符，换行命令不会与单行命令碰撞。
- 远端只能 `once/deny`，不能 `always`；远程代理阻断内部 request/wait 端点并覆盖可信远程标记，远程页面不展示长期授权按钮。
- pending 同时受全局和单会话容量限制，只保留决策所需最小字段；超量返回 429，单条长期规则目标最多留存 16 KiB。
- 旧 WebSocket 的迟到消息不会投递到新会话；已关闭卡片墓碑只在 pending 快照请求飞行期间存在，请求结束即释放。
- Hook 轮询改为单飞，慢响应不会叠加多个 wait 请求。

## 权限链路等价集成验证

通过真实路由处理器和内存替身执行请求链路：

- 已映射 Claude session：HTTP 200，返回请求 ID，向正确 Neko sid 广播权限卡片，并触发 `pending=true`。
- 未映射 Claude session：HTTP 404，产生一条隐私安全 warning。
- 恶意 session ID：warning 只显示 `invalid`，不包含控制字符、工具参数、cwd 或完整输入。
